packages/shared — @drillex/shared

Pure TypeScript library (compiled via tsc), dependency-free aside from Zod. Provides: enums.ts, schemas.ts (Zod schemas for every domain input — logins, readings, shift reports, job cards, maintenance), rbac.ts (the permission matrix), jobcards.ts / maintenance.ts (business calculation helpers e.g. nextCycle, scheduleStatus), plus its own vitest unit tests.

Full request/response schemas are published live via Swagger UI at /api/docs on a running instance.

Testing & CI

What's covered

  • apps/api/test/api.e2e.ts — vitest + supertest against a live MySQL: auth/RBAC, daily readings + alerts, shift reports + approval, offline sync idempotency/conflicts
  • packages/shared/src/schemas.test.ts — vitest unit tests for Zod schemas and calc helpers
  • infra/load/k6-smoke.js — 200 VU load test against the §9.5 NFR thresholds (run manually/CI-optional)

Gaps

  • apps/web has no test suite configured
  • apps/mobile has Jest configured but no test files present
  • CI builds/tests API and web only — mobile isn't built or tested in CI

CI pipeline (.github/workflows/ci.yml, Node 22 / pnpm 9.15.4, MySQL 8 service container):

pnpm install --frozen-lockfile
prisma generate && prisma migrate deploy && db:seed
pnpm typecheck
pnpm test
pnpm --filter @drillex/api --filter @drillex/web build
