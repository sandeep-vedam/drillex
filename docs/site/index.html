How this documentation set is organized

The Presentation is the fastest read — start there for a stakeholder-level summary. The PRD and SRS describe what the product must do and for whom, at increasing levels of formality. The Architecture and Technical Details pages describe how it is actually built, sourced directly from the current codebase (Prisma schema, Nest modules, Next.js routes, React Native screens).

Source of truth This site is generated from the code and from docs/DEVELOPMENT_PLAN.md as of 2026-08-22. Where the original plan and the shipped implementation diverge (e.g. the mobile offline layer), the documents below describe what is actually implemented and call out the divergence explicitly.
