Executive Overview

Drillex Ops

A single platform that takes a drilling site off paper: operators log equipment and production from the field, supervisors approve, technicians run maintenance, and managers get the reports — all from the same data.

The problem

Drilling-site operations run on a mix of paper log sheets, spreadsheets and phone calls: pre-start equipment checks on clipboards, shift production totals re-typed at the end of the day, maintenance tracked from memory or a whiteboard, spare parts counted by walking the store. Nothing is connected — a fault noticed at 6am doesn't reach the maintenance team until someone happens to mention it, and a manager wanting last month's chemical usage has to chase five different people for five different numbers.

The solution

Drillex Ops gives every role one app that fits how they already work:

Field crew (mobile)
Operators and technicians work offline-first on a phone — daily readings, shift reports, job cards, all queued and synced automatically.
Supervisors & managers (web)
A browser dashboard to approve shift reports, track maintenance due, action low stock, and review 7 report types.
Admins (web)
User and device management, role-based access, and audit trail across the whole site.

How data flows through a shift

Core workflow areas

Field data capture

  • Daily pre-start equipment readings, with automatic alerts on faults
  • Drilling shift production reports (depth, meters, chemicals used)
  • Photo & signature capture, all queued offline

Maintenance & parts

  • Hour-meter and calendar-based maintenance schedules with reminders
  • Job cards with parts consumption, auto stock deduction
  • Low-stock alerts and purchase-request workflow

Approvals & accountability

  • Supervisor approve / unlock workflow on shift reports
  • Role-based access down to 5 roles, mandatory 2FA for managers
  • Full audit trail on every mutating action

Reporting

  • 7 report types: production, utilisation, maintenance, job history, chemical usage, asset health, employee activity
  • PDF + XLSX export, email share, automated month-end run
  • 24-month archive retention

Why this stack

NestJS + Prisma + MySQL gives a strongly-typed, RBAC-guarded API with a single schema shared by every client. A bare React Native app (not Expo) with a hand-rolled offline outbox keeps the mobile build small and gives full control over sync semantics for a site with unreliable connectivity. Next.js serves both the supervisor/manager dashboard and the admin console as one role-gated web app. A shared @drillex/shared package keeps validation rules (Zod) and the permission matrix identical across all three surfaces, so a rule only has to be written once.
