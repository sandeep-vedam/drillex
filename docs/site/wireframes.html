Wireframes

Low-fidelity screen layouts for the four flows that carry the seeded demo data (pnpm db:demo) end to end: an operator logging a daily equipment check, a driller logging shift production, the mobile home screen that launches both, and the web Reports page that turns 30 days of that data into the seven management reports.

How to read these Boxes and lines stand in for real components — they show structure, grouping, and field types, not final visual design. Every field, control, and label below is sourced from the current implementation (apps/mobile/src/screens/*.tsx, apps/web/src/app/(app)/reports/page.tsx) so this page stays a truthful map of what exists, not a proposal.
